# 🚗 Smart Parking Management System

### Design Pattern Lab Project

## 1. Project Description

The Smart Parking Management System is designed to make parking easier, faster, and more efficient. It helps users find available parking spaces, manage vehicle parking, and reduce the time spent searching for parking slots.

This project demonstrates the use of object-oriented programming and software design patterns to organize a smart parking solution.

## 2. Problem Statement

**"Design a smarter way to manage parking spaces."**

In crowded areas, drivers often face difficulties finding available parking spaces. Manual parking management can lead to traffic congestion, time wastage, and inefficient use of parking areas.

The proposed system provides a structured approach to managing parking slots and vehicle allocation.

## 3. Objectives

- To manage parking slots efficiently.
- To identify available and occupied parking spaces.
- To simplify vehicle parking and slot allocation.
- To support different types of vehicles.
- To demonstrate reusable software design patterns.

## 4. Main Features

- Add and manage parking slots.
- Check parking slot availability.
- Allocate available slots to vehicles.
- Display parking slot details.
- Support different vehicle types such as cars and bikes.
- Design for multiple payment methods.
- Provide a foundation for sensor-based parking updates.

## 5. Design Patterns Used

The UML design demonstrates the following four design patterns:

| Design Pattern    | Purpose                                                 |
| ----------------- | ------------------------------------------------------- |
| Singleton Pattern | Ensures a single ParkingManager instance.               |
| Factory Pattern   | Creates different vehicle objects such as Car and Bike. |
| Strategy Pattern  | Supports different payment methods.                     |
| Observer Pattern  | Updates parking displays when slot status changes.      |
